Smart Campus Navigation System

A mini web-based campus navigation application built using Leaflet.js and OpenStreetMap.

Features

- Interactive campus map
- Building markers
- Search functionality
- Route navigation
- Draggable live routes
- Modern UI

Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap

How to Run

1. Download project
2. Open folder in VS Code
3. Run using Live Server

Project Goal

To help users navigate a college campus easily using map-based navigation.
